5) How you test these services (important)
A) Run from WebTools → Service Engine

Go to: https://localhost:8443/webtools/control/main

Service Engine → Run Service
Example inputs:

Create PayrollPeriod

serviceName: payrollCreateEntity

entityName: PayrollPeriod

orgPartyId: Company

fields

{
  "payrollPeriodId":"P2026_01",
  "periodName":"Jan 2026",
  "startDate":"2026-01-01",
  "endDate":"2026-01-31",
  "statusId":"PAY_PER_OPEN"
}


Process Payroll Run

serviceName: processPayrollRun

orgPartyId: Company

payrollRunId: 10001

recalculate: true

B) Call via curl (authenticated session required)

If you already use OFBiz JSON-RPC or REST layer, we can wire these services to your /rest/services/... endpoint, but the service implementation above is correct regardless of controller.
